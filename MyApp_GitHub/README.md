# MyApp

SwiftUI chat demo converted from Swift Playground source files.

GitHub Actions builds an unsigned iOS IPA. Apple signing is intentionally left to the owner.

## DeepSeek API key

Do not commit a real DeepSeek API key to GitHub. `AIService.swift` contains only a placeholder.

## Avatar image

Add the user's `administerphoto` image into:

`MyApp/Assets.xcassets/administerphoto.imageset/`

The image filename can be supplied at 1x/2x/3x as appropriate; the asset name must remain `administerphoto`.
